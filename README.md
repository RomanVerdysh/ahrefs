Плагин добавляет небольшую поле, в которое можно вставить N доменов просто списком, а скрипт будет автоматически брать по 200 доменов из списка, грузить их в Батч Анализ Ахрефса, ждать таблицу и потом экспортировать данные. В скрипте стоят задержки. Работает, даже вкладка не активна. 

<h2>Установка Tampermonkey</h2>
<ol>
  <li>Скачиваем сам плагин для Google Chrome - <a href="https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo">tampermonkey</a></li>
  <li>Создаем в нем "Создать новый скрипт"</li>
  <li>Удаляем все, что там написано</li>
  <li>Вставляем содержимое моего файла **Ahrefs Batch Alanysis Export.js**</li>
  <li>Сохраняете</li>
</ol>

Кроме стилей настроек нет.

<h2>Дисклеймер</h2>
Я не знаю, заблочит ли Ахрефс за автоматизацию. Меня не блочил, проверял за раз где-то 30к доменов.
Иногда таблица Ахрефса не прогружается и скрипт не может ничего сделать, просто CTRL + F5 для обновления страницы и стартуем для оставшихся доменов.
О всех косяках пишите в телегу в комменты + пояснение.
